# Self-hosted typefaces

The browser host serves the Latin WOFF2 subsets used by its landing page so
opening OpenBundle does not contact a third-party font CDN.

- `roboto-slab-latin.woff2` — Roboto Slab variable weight file from Google
  Fonts (`fonts.gstatic.com`, v36), Apache-2.0 licensed.
- `spectral-{400,600,700}-latin.woff2` — Spectral files from Google Fonts
  (`fonts.gstatic.com`, v15), SIL Open Font License 1.1.

The complete upstream licenses are included beside the font files.
